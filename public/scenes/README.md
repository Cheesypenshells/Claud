# Foto realistis karakter (opsional)

Taruh foto karakter **fiksi** di `public/characters/<id>/<mood>.jpg` (atau .webp / .png).
Mood: neutral, happy, amused, shy, curious, annoyed, uncomfortable, leaving — minimal `neutral.jpg`.
Opsional: `portrait.jpg` (kartu), `walk.mp4` (video berjalan sebelum disapa).
Latar foto (opsional): `public/scenes/<scene>.jpg` — scene: city, park, beach, market, riverside.

Prompt untuk tiap karakter & ekspresi: `docs/prompt-pack-karakter.md` (buat ulang dengan `npm run prompts`).
Jangan memakai foto orang sungguhan atau wajah mirip selebriti.
