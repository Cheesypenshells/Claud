# Studio Konten: Talent x Claude

👉 **Mulai dari [`00-RENCANA-INDUK.md`](00-RENCANA-INDUK.md)**: target, step by step, mesin mingguan.

Kamu = **talent** (punya cerita & wajah).
Claude = **tim kreatif** (riset, ide, script, caption, kalender konten).

## Alur kerja
1. **Isi profil** → `talent/profil.md` (sekali saja).
2. **Setor cerita** → bikin file baru di `stories/` pakai `templates/cerita-mentah.md`,
   atau langsung ceritakan di chat dan Claude yang menuliskannya.
3. **Claude olah** → setiap cerita dipecah jadi beberapa konten di `konten/`:
   script Reels/TikTok, caption, hook alternatif, ide carousel.
4. **Kamu syuting** sesuai script → posting → kabari hasilnya (views, komen)
   supaya konten berikutnya makin tajam.

## Struktur folder
| Folder | Isi |
|---|---|
| `talent/` | Profil, gaya bicara, batasan |
| `stories/` | Cerita mentah dari kamu |
| `konten/` | Script & caption siap pakai |
| `templates/` | Format standar |
