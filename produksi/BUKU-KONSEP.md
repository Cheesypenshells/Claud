# Buku Konsep: Template Edit Tetap
> Setiap batch klip dari George otomatis diedit mengikuti template yang cocok.
> Semua template wajib lolos `produksi/STANDAR-KUALITAS.md` (tajam, bergerak, ada suara, hook detik 0–1).
> Musik trending ditambahkan George saat upload di Instagram. Klip AI realistis → label AI.

---

## T1 · Promo Keju Lumer (@cheesypenshells) · 10–12 dtk
**Bahan:** 2–3 klip keju ditarik, 1–2 klip api, 1 klip booth/antrean.
| Detik | Isi | Teks | Suara |
|---|---|---|---|
| 0–1,5 | Close-up keju ditarik (momen paling panjang) | – | Suara asli |
| 1,5–4 | Api / torch membakar keju | "oyster bakar **MOZZARELLA**" (atas, area gelap) | Desis api |
| 4–7 | Keju ditarik sudut lain, slow motion | – | – |
| 7–9 | Booth ramai / antrean | "[KOTA] · [tanggal]" | Keramaian |
| 9–11 | Kartu logo krem | harga + promo (yang sudah dikonfirmasi) | – |
Potongan 0,8–2,5 dtk. Tidak ada foto diam, kecuali logo.

## T2 · Reaksi Pembeli (@cheesypenshells) · 12–15 dtk
**Bahan:** 1–3 klip pembeli makan pertama kali (dengan izin yang direkam).
| Detik | Isi | Teks |
|---|---|---|
| 0–1 | Wajah pembeli sebelum gigit | "pertama kali makan oyster..." |
| 1–6 | Gigit → reaksi | – (biarkan suara asli) |
| 6–10 | Close-up keju + reaksi kedua | "reaksinya 😂" (tanpa emoji di render) |
| 10–13 | Booth + lokasi | "[KOTA] · [tanggal]" |

## T3 · Editorial B&W (@geov10) · 15–25 dtk
**Bahan:** klip George (diam / jalan / kerja di booth), voice over George (opsional).
- Grade hitam-putih, grain, cahaya samping, slow push-in.
- Teks serif: baris biasa + baris *miring* (2 baris per adegan, 3–4 adegan).
- Penutup tanda tangan "George Vallentino · Founder, Cheesy Pen Shells".
- Isi kalimat = dari cerita asli George, bukan karangan.

## T4 · Vlog Kota Baru (@geov10) · 25–40 dtk
**Bahan:** selfie perjalanan, bongkar booth, hari pertama, malam setelah tutup.
| Bagian | Isi |
|---|---|
| Hook 0–2 | Selfie ngomong: "Kota ke-[x]. [KOTA]." |
| 2–20 | Potongan cepat perjalanan + persiapan, subtitle kata per kata |
| 20–30 | 1 momen jujur (capek / sepi / ramai) |
| Penutup | "Next: [kota berikutnya]?" → ajak komen |

## T5 · Cerita Founder (@geov10) · 40–60 dtk
**Bahan:** talking head George (cerita 1 menit) + B-roll booth/api.
- Hook 3 detik pertama = kalimat paling kuat dari cerita.
- Subtitle kata per kata (maks 3 kata per layar).
- Setiap 4–6 detik disisipi B-roll supaya tidak monoton.
- Akhir: "Part [n] besok. Follow."

---

## Cara pakai per batch
1. George kirim zip per kategori (keju / api / pembeli / George / perjalanan).
2. Claude cek tiap klip (cuplikan gambar), beri nilai, catat di `produksi/stok-klip.md`.
3. Claude pilih template yang cocok → render → kirim hasil + **instruksi edit CapCut**
   (kalau George/editor mau finishing manual: beat, efek suara).
4. Klip yang sudah dipakai ditandai, supaya tidak berulang.
